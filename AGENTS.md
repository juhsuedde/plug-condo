# PlugCondo — Agent Instructions

## Project Overview
React 19 + TypeScript + Supabase app for EV charging management in Brazilian condominiums. Originally generated by Lovable, deployed on Vercel.

## Commands
- `npm run dev` — Start dev server (port 3000)
- `npm run build` — Production build (uses Nitro for Vercel)
- `npm run lint` — Run ESLint
- `npm run format` — Format with Prettier

## Architecture
- **Routing**: TanStack Router with file-based routing in `src/routes/`
- **Layout**: `_authenticated.tsx` gates access; redirects to `/pendente` if `perfis.status_aprovacao != 'aprovado'`
- **State**: TanStack Query + React Query; `useAuth` provides `user`, `perfil`, `loading`
- **Supabase Client**: `src/integrations/supabase/client.ts`

## Edge Functions (Deno)
| Function | Purpose | Auth |
|----------|---------|------|
| `create-pix-payment` | Creates Pix QR via Mercado Pago | JWT |
| `mercado-pago-webhook` | Handles payment status webhooks | No |
| `process-queue` | Notifies next person in queue | No |
| `calculate-reservation-cost` | Calculates kWh consumed cost | No |
| `check-reservation-grace-period` | Cancels reservations not started within 15min | No |
| `confirm-queue-reservation` | Confirms reservation from queue | JWT |

## Key Files
- `src/lib/auth.tsx` — Auth context with perfil fetching
- `src/routes/_authenticated/pendente.tsx` — Pending approval screen
- `src/routes/_authenticated/notificacoes.tsx` — Notifications with filters and pull-to-refresh

- `vercel.json` — Vercel deployment config

## Common Pitfalls
- Edge Functions use Deno runtime (not Node). Use `fetch`, not `axios`
- Supabase client in Edge Functions: `https://esm.sh/@supabase/supabase-js@2`
- Payment webhooks must return 200 even on errors (to prevent MP retries)
- Approval flow: `perfis.status_aprovacao` can be `pendente`, `aprovado`, or `rejeitado`
- For Vercel deployment, always use Nitro (`nitro/vite` plugin in vite.config.ts)
- When deploying to Vercel, add all env variables in Vercel dashboard (not just .env)
- `VITE_SUPABASE_PUBLISHABLE_KEY` is required by Supabase Auth client
